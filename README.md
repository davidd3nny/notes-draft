# Notes: сайт-концепт

Одностраничный сайт для Notes Gastronomy & Bar, который читается как партитура одного дня:

- **Ноты дня.** Пять линий нотного стана — пять служб: завтраки, пекарня, пицца, кухня, бар. Коралловая черта стоит на текущем времени Баку.
- **Меню из частей, как произведение.** I Утро, II День, III Вечер, десерты, IV Бар. Всё на одной странице.
- **Три языка:** AZ, RU, EN. Есть статус «открыто сейчас» и бронь через WhatsApp.

Сайт собирается сам. Вы меняете один файл с данными, `sites/notes/data.json`, а GitHub через 1–2 минуты публикует новую версию:
**https://davidd3nny.github.io/notes-draft/**

Это концепт для показа владельцу. Меню, фотографии и рисунки взяты с сайта notes.az, цены нужно подтвердить. Поисковикам страница закрыта (см. «Когда сайт станет настоящим»).

## Что где лежит

| Папка или файл | Что внутри | Кто меняет |
|---|---|---|
| `sites/notes/data.json` | меню кухни и бара, цены, часы, службы, контакты, тексты на трёх языках | Вы |
| `sites/notes/index.html` | разметка страницы | при доработке дизайна |
| `sites/notes/style.css` | оформление | при доработке дизайна |
| `sites/notes/app.js` | поведение: ноты дня, меню, языки, время | при доработке |
| `sites/notes/photos.js` | фотографии, вшитые в страницу | не трогать (см. «Фотографии») |
| `sites/notes/art/defs.svg` | логотип Notes и линейные рисунки в векторе | не трогать |
| `sites/notes/fonts.json`, `fonts/` | шрифты и их лицензии (OFL) | не трогать |
| `shared/core.js` | общие помощники: язык, время в Баку, цены | не трогать |
| `build.py` | сборщик: склеивает всё в один файл и проверяет данные | не трогать |
| `.github/workflows/deploy.yml` | робот «Сайт»: собирает и публикует | не трогать |

## Первый запуск (один раз)

1. **Settings → Pages**, поле **Source**: выберите **GitHub Actions**. Больше ничего не нажимайте: робот уже лежит в репозитории, кнопки Configure у шаблонов не нужны.
2. **Actions**: первый запуск робота «Сайт» мог упасть до шага 1. Откройте его и нажмите **Re-run all jobs**.
3. Через минуту сайт откроется по ссылке выше.

## Как править data.json

Откройте файл на github.com и нажмите карандаш (**Edit**). После правки нажмите **Commit changes**.

Правила JSON, их всего четыре:
- тексты и названия полей пишутся в двойных кавычках: `"name"`;
- цены пишутся числом, без кавычек: `9`, `3.5`. Знак ₼ сайт ставит сам;
- между элементами ставится запятая, после последнего элемента в списке её нет;
- комментариев в JSON не бывает.

Ошибка сайт не сломает. Робот откажется собирать, на сайте останется прошлая версия, а в отчёте будет по-русски написано, что и в какой строке не так.

### Блюдо

```json
{"name": {"az": "Burrata / pomidor / trüfel sousu", "ru": "Буррата / томаты / трюфельный соус", "en": "Burrata / tomato / truffle sauce"}, "price": 22},
```

- До первой ` / ` идёт название блюда, после неё состав. Сайт покажет состав мелким шрифтом, через запятую.
- Текст нужен на всех трёх языках, иначе сборка остановится.

Необязательные поля:

| Поле | Что это | Пример |
|---|---|---|
| `note` | вес, штуки, происхождение | `"note": {"az": "2 əd.", "ru": "2 шт.", "en": "2 pcs"}` |
| `desc` | полное описание вместо состава после ` / ` | как у «Notes set» |
| `sig` | фирменное блюдо, рядом встанет нота ♪ | `"sig": true` |
| `variants` | одно блюдо с разными ценами | как у «Цезаря» |

Чтобы добавить блюдо, скопируйте соседнюю строку целиком, с запятой в конце, и поменяйте текст и цену. Чтобы убрать блюдо, удалите его строку.

### Разделы кухни

Каждый раздел лежит в списке `kitchen`:

| Поле | Что это |
|---|---|
| `id` | адрес раздела на странице, например `breakfast` (не меняйте) |
| `part` | часть дня: `morning`, `day` или `evening` |
| `service` | служба с часами: `breakfast`, `bread`, `pizza`. Вне этих часов раздел бледнеет с подписью «На сегодня закончились» |
| `boxed` | раздел на цветной вставке, как Raw bar и пицца |
| `compact` | короткие позиции в две колонки, как добавки и хлеб |
| `photo`, `photoAlt` | фото в конце раздела и подпись к нему |

### Напитки и вино

```json
{"name": "Rhubarbie", "price": 18, "desc": "Rhubarb gin, strawberry vermouth, tomato water, vanilla", "sig": true},
{"name": "Sirab", "prices": {"0,33 L": 7, "0,75 L": 10}},
{"name": "Ruffino Chianti DOCG", "org": "Italy, Tuscany", "glass": 14, "bottle": 80},
```

- Названия и составы напитков написаны по-английски, как в барной карте Notes.
- `glass` — цена бокала, `bottle` — цена бутылки. Вино с `glass` само попадает в список «Бокалом».
- Страну и регион вина сайт переводит по словарю `geo`. Для нового региона добавьте в `geo` строку вида `"Tuscany": {"az": "Toskana", "ru": "Тоскана", "en": "Tuscany"}`.

### Часы и службы

```json
"hours": {"weekday": {"open": "11:00", "close": "00:00"}, "weekend": {"open": "10:00", "close": "00:00"}},
{"id": "breakfast", "weekday": ["11:00", "13:00"], "weekend": ["10:00", "15:00"], "to": "breakfast", ...},
```

- Время Баку. Будни — с понедельника по пятницу, выходные — суббота и воскресенье. Закрытие в полночь пишется как `"00:00"`.
- По этим часам сайт сам пишет «Сейчас открыто, до…», «До закрытия 40 мин», «Сейчас закрыто. Откроемся в…» и рисует ноты дня.
- `to` — раздел, к которому ведёт линия стана.

### Контакты и переключатели

| Поле | Что это |
|---|---|
| `phone` | номер для звонка и WhatsApp: `+994105551050`, без пробелов |
| `phoneDisplay` | как номер выглядит на сайте |
| `email`, `address`, `mapUrl` | почта, адрес на трёх языках, ссылка «Открыть карту» |
| `instagram`, `facebook`, `youtube`, `delivery` | ссылки на соцсети и доставку |
| `draft` | `true` — плашка «Концепт» и закрытый для поисковиков сайт |
| `openLists` | `true` — полная винная карта и крепкие напитки раскрыты сразу |
| `ui` | все подписи интерфейса на трёх языках, в том числе сервисный сбор (`fee`) |

## Фотографии

Фото вшиты в `photos.js`, поэтому страница работает одним файлом, даже без интернета. Сейчас там снимки с сайта notes.az, кадрированные по центру блюда. Для настоящего сайта нужны оригиналы от фотографа Notes и логотип в векторе от их дизайнера. С ними `photos.js` пересобирается заново.

## Когда сайт станет настоящим

1. В `data.json` поставьте `"draft": false`. Исчезнет плашка «Концепт», а `robots.txt` откроет сайт поисковикам.
2. В `sites/notes/index.html` удалите строку `<meta name="robots" content="noindex">` вместе с комментарием над ней.
3. Подтвердите с Notes цены, часы работы и номер WhatsApp. Если у десертов появятся цены, витрину можно превратить в меню.
4. Подключите домен заведения: GitHub Pages → Cloudflare.

## Собрать на своём компьютере

```bash
python3 build.py notes
open out/notes.html
```

Подойдёт любой Python 3, сторонние библиотеки не нужны.

Для проверки к адресу страницы можно дописать параметры:

| Параметр | Что делает |
|---|---|
| `?lang=ru` | язык: `az`, `ru`, `en` |
| `?at=09:00` | показать сайт так, будто в Баку сейчас 09:00 (до открытия) |
| `?day=6` | будто сегодня суббота (`0` воскресенье … `6` суббота) |

Параметры складываются: `?lang=en&at=21:00`. Так удобно показывать владельцу, как сайт меняется в течение дня.

## Если что-то пошло не так

**Робот во вкладке Actions стал красным.** На сайте осталась прошлая версия, гости ничего не заметили. Откройте упавший запуск, шаг «Собрать сайт»: там по-русски написано, что не так. Частые причины:
- лишняя или пропущенная запятая;
- цена в кавычках или с текстом (`"12 AZN"`);
- текст есть не на всех трёх языках.

**Правка прошла, а сайт старый.** GitHub Pages держит копию страницы до 10 минут. Обновите страницу с очисткой кэша (Cmd + Shift + R) или откройте адрес с `?v=2` в конце.
